# Skill: calculate-sales-kpis

## Trigger
Invoked by the Sales Analytics Agent whenever a business question or dashboard view requires numerical metrics, after data quality has passed or warned (never after a block).

## Inputs
- `df`: validated, filtered pandas DataFrame in the caller's authorized scope.
- `filters`: dict of applied filters (business_unit, area, district, territory, product, period).
- `period` / `prior_period` (optional): for growth comparisons.
- `group_col` (optional): for contribution breakdowns (e.g. `territory`).

## Ordered Procedure
1. Apply `filters` to `df` before any aggregation.
2. Compute Actual Sales = `sum(sales_value)`.
3. Compute Target Sales = `sum(target_value)`.
4. Compute Achievement % = Actual / Target * 100. If Target == 0 or unavailable, return `value=null` with `reason="target sales is zero or unavailable"`.
5. Compute Variance to Target = Actual - Target.
6. If prior-period data is supplied, compute Growth % = (Current - Prior) / Prior * 100. If Prior is `None` or 0, return `value=null` with an explicit reason.
7. If a parent scope is available, compute Contribution % = Entity Sales / Parent Sales * 100. If Parent == 0, return `value=null` with a reason.
8. Round currency to 2 decimals and percentages to 1 decimal only for display; retain full precision internally for further computation.
9. Wrap every metric in a `KPIResult` carrying `metric, filters, period, value, reason, display` so it can be converted to evidence.
10. Never compare incomplete periods without labeling the limitation explicitly in the caller's output.

## Output Schema
List/dict of `KPIResult`:
```
{"metric": str, "filters": dict, "period": str|null, "value": float|null, "reason": str|null, "display": str}
```

## Failure Behavior
- A zero or missing denominator never raises — it returns `null` + a clear reason string, which the Insight Agent must surface as a limitation, not omit.
- All KPI math lives in `src/analytics/kpi.py`; this skill only orchestrates calls into it. No metric may be computed inline in prompt text.

## Validation Checklist
- [ ] All 5 core KPIs computed via `src/analytics/kpi.py`, never inline
- [ ] Zero/missing-denominator cases return null + reason, not an exception or a fabricated number
- [ ] Filters applied before aggregation
- [ ] Currency rounded to 2dp, percentages to 1dp for display only
- [ ] Full precision retained for any chained calculation
- [ ] Every KPIResult convertible to an EvidenceItem
